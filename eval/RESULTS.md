# ASMR 자막·번역 실험 결과 (2026-10-09)

동인음성(ASMR·귀청소·잠재우기 등) 일본어 자막 앱의 음성 인식 구성과 번역 경로를 고르기 위한 실험이다.
대사 원문과 결과 텍스트는 구매 작품 내용이라 이 저장소에 넣지 않는다(`eval/data`, `eval/out`은 .gitignore).

## 1. 평가 방법

- **평가셋:** 동인음성 7개 작품에서 14트랙, 3.2시간. 정답 글자는 작품에 딸린 일본어 대본의 대사, 정답 타임라인은 중국어 자막(VTT/LRC)의 줄 시간.
  `w8sleep`은 숨소리만 있는 10분(정답 "대사 없음")으로 환각 확인용이다.
- **분할(작품 단위, 과적합 방지):** 튜닝은 4개 작품(w1~w4, 8트랙)에서만 하고, 검증 3개 작품(w5~w7 + w8sleep, 6트랙) 수치는 마지막에 보고한다.
- **GPU:** Runpod RTX 3090 24GB(보안 클라우드, EU-CZ-1). 지난 실험(css52, RTX 4090)과 GPU가 다르다.
- **채점:** `eval/metrics.py`와 같은 함수(`score_split.py`).

| 열 | 뜻 |
|---|---|
| CER | 글자 오류율(NFKC, 글자·숫자만). 대본 표기와 다른 한자·가나 선택도 오류로 센다 |
| 읽는 소리 CER | 양쪽을 Sudachi 읽기(히라가나)로 바꾼 뒤의 오류율. 표기 차이를 빼고 "들은 말이 맞는지"를 본다. **주 지표** |
| 누락/삽입 | 읽는 소리 CER 중 빠진 글자 / 더 들어간 글자 비율 |
| 잡은 대사 | 중국어 자막 줄 중 길이 15초 이하 자막이 절반 이상 덮은 비율(대사를 놓치지 않았는지) |
| 깨진 자막 | 15초 넘는 자막 한 줄이 덮는 시간 비율(20~40초짜리 한 줄은 보기에 깨진 자막) |
| 가짜 자막 | 정답 자막 어느 줄과도 겹치지 않는 자막 시간 비율(대사 없는 곳의 가짜 자막) |
| 반복 | 같은 2~6글자가 5번 넘게 이어지는 줄 수(반복 환각) |
| 숨소리 트랙 글자 | w8sleep(대사 없음)에서 나온 글자 수(환각) |
| RTF / VRAM | 처리 시간 ÷ 음성 길이, 최대 GPU 메모리. 실험은 여러 작업을 같은 GPU에서 동시에 돌려서, RTF·VRAM은 GPU를 혼자 쓰는 상태에서 w7t2(10.6분) 하나로 따로 쟀다 |

WhisperJAV pyproject 주석대로 이 모델은 transformers≥5.13이 필요한데 WhisperJAV의 Qwen 경로는 transformers<5로 고정돼 있다. 그래서 `qwen-asr` 패키지로 같은 WhisperSeg 구간에서 직접 돌렸더니 동작했다: 단독 0.157(기본 Qwen3-ASR 0.170보다 좋고 숨소리 트랙 환각 0), Whisper 결과를 문맥으로 주면 오히려 0.250으로 나빠짐, 신뢰도 선택(sel2)은 0.146으로 anime-whisper 단독과 같음.
- **WhisperJAV balanced**(large-v2, 기본): 0.315로 낮다. `--model whisper-ja-1.5B`로 바꾸면 0.240.
- **4(a) 병합(mrg-*):** pass1 = {anime-whisper(wj-qwen-anime), whisper-ja-1.5B(wj-balanced-ja15b), turbo(cmb-large-v3-turbo-W)}, pass2 = Qwen3-ASR(wj-qwen), 병합 = {pass1_primary, smart_merge, longest}을 앙상블을 다시 돌리지 않고 WhisperJAV `MergeEngine`으로 합쳤다. 모두 pass1 단독보다 나빴다(pass2 줄이 더해져 삽입 오류가 늘어남). 숨소리 트랙 글자 28은 Qwen 쪽(wj-qwen)의 환각이 섞인 것.
- **4(b) 문맥(Qctx):** 같은 구간의 Whisper 결과를 Qwen3-ASR의 context(시스템 프롬프트)로 넘겼다. Qwen 단독(Q)보다는 좋아지지만(anime 0.170 → 0.156) Whisper 단독(W 0.146)보다는 나쁘다.
- **4(c) 신뢰도 선택(sel1~3):** sel1 = Qctx가 비거나 반복이면 W, sel2 = W의 avg_logprob ≥ -0.6이고 압축비 ≤ 2.4면 W 아니면 Q, sel3 = 둘 중 긴 쪽. anime-whisper에서는 sel2 = W(0.146)와 같고, turbo에서는 sel2가 0.176 → 0.166으로 좋아졌다.
- **3. Qwen3-ForcedAligner로 시간 다시 맞추기:** (1) W-fa = 구간 안에서 Whisper 글자를 정렬해 첫 글자~마지막 글자로 자막 시간을 줄임 → 글자는 같고 잡은 대사가 97% → 94%로 조금 떨어짐(자막이 짧아져 중국어 자막 줄과 겹치는 부분이 줄어듦). (2) WhisperJAV `--qwen-timestamp-mode aligner_interpolation`(wj-qwen-fa) → 글자 0.188 → 0.191, 잡은 대사 97% → 92%. 대신 **자막 시작 시각이 중국어 자막 줄 시작에 더 가까워졌다**(중앙값 차이: wj-qwen 0.59초 → 0.28초, anime-whisper 구간별 0.24초 → W-fa 0.13초). 시간은 더 정확해지지만 자막이 짧아져 겹침 기준 지표가 떨어지는 맞바꿈이고, PyTorch가 필요해 앱에는 넣지 않았다(구간별 방식의 VAD 경계로 이미 0.23초).
- **돌리지 않은 것:** WhisperX(지시상 참고용)와 WhisperJAV README의 "maintainer's favorite"(Qwen + htdemucs + enhance-for-vad + TEN, `enhance` extra 필요)는 Pod 디스크(50GB)·시간이 모자라 돌리지 않았다.

## 6-1. 번역 비교: Gemini 무료 vs 로컬 LLM

### 조건
- **입력 두 가지:** (1) 정답 대본 287줄 — 7개 작품에서 장르 특성(일상 대화, 츤데레·아가씨·보쿠·메이드 경어·갸루어 말투, 속삭임, 의성어·의태어 반복, 신음 표기)이 들어간 구간 250줄 + **합성 성인 대사 37줄**. 평가셋 작품이 모두 전연령이라(대본에서 성인 어휘 검색 결과 없음) 성인 장면은 장르 관례대로 직접 쓴 문장(등장인물은 모두 성인: 메이드, 대학생 갸루, 회사 선배)이다.
  (2) ASR 결과 362줄 — 같은 구간을 가장 좋은 ASR 구성(anime-whisper + WhisperSeg 구간별) 결과에서 잘라 낸 것(실사용 조건, 합성 대사 제외).
- **같은 앱 코드로 번역:** 앱에 저장된 시스템 프롬프트·번역 노트, `<p id>`·`<o>원문</o>` 되풀이, 문맥 줄 3줄, 청크 60줄, 줄 밀림 검사, 실패 시 청크 반씩 나눠 재시도. Gemini는 `GeminiTranslator`(키 24개, 자동 모델 순서, 추론 minimal), 로컬 LLM은 새 `OpenAICompatTranslator`(llama.cpp b11518 `llama-server`, Pod RTX 3090, 생각 끔 `--reasoning off`).
- **모델:** Command R7B "ARX"라는 이름의 저장소는 Hugging Face에서 찾지 못해 지시대로 `bartowski/c4ai-command-r7b-12-2024-abliterated-GGUF` Q6_K(6.6GB, **CC-BY-NC 비상업**)를 썼다. Gemma4는 `HauhauCS/Gemma4-26B-A4B-Uncensored-HauhauCS-Balanced` Q4_K_M(16.8GB, Apache-2.0).

### 결정
- **Runpod 번역 경로의 기본 모델은 Gemma4 26B-A4B**로 정했다. 품질은 Gemini와 비슷하거나 조금 높고, 차단·순화가 없고(이 장르의 핵심 약점), 더 빠르다.
- 24GB GPU에서 음성 인식 모델(anime-whisper 약 7GB)과 함께 올리기 위해 원격 옵션은 같은 모델의 IQ4_XS(13.9GB)를 받는다.
- 앱 전체의 기본 번역은 그대로 **Gemini**(설정 없이 무료). 원격 실행을 고르면 원격 LLM(Gemma4)이 기본으로 켜진다(끄면 Gemini).
- Command R7B는 이 작업에 쓸 수 없는 수준이라 선택지에는 남기되 "품질 낮음"으로 표시했다.
